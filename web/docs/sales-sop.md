# 3 天成交 SOP（销售运营手册）

系统角色：官网负责「制造线索 + 建立信任」，本 SOP 负责「3 天内把线索变定金」。
后台仪表盘的「未处理线索」必须每日清零。

## Day 0 — 线索进入（系统自动）

触发点：报价器提交 / 联系表单 / 邮件 / WhatsApp / 微信。
- 系统：Lead 入库 + （已配置时）webhook 转发到你的建联系统
- 报价器线索自带「预估区间」——首聊前先看，**不要报出比报价器更低的价**

## Day 1 — 首响与需求挖掘

- **KPI：4 小时内首次响应**（官网 FAQ 公开承诺了这一点，违背即失信）
- 30 分钟 Discovery Call，提纲：
  1. 现在的流程长什么样？最痛的 20 分钟发生在哪？
  2. 谁用？多少人用？多久用一次？
  3. 不做这个项目，每个月损失什么？
  4. 预算区间确认（对照报价器档位：Light $5–15k / Standard $15–50k / Flagship $50k+）
  5. 决策人是谁？签字流程多长？
- Call 后 2 小时内：AI 辅助产出《需求摘要 + 方案草案 + 初步报价》发给客户
  （用 Claude：贴上通话纪要 → 摘要 + 三段式方案 + 里程碑报价）

## Day 2 — 方案确认

- 客户反馈 → 30 分钟方案会（销售 + 技术）
- 当天产出：正式 SOW + 固定报价 + 里程碑付款表 + 合同草案
- 异议处理速查（与官网 FAQ 口径一致）：
  - "太贵" → 拆里程碑，首期只买最痛的部分（Light 档进入）
  - "怕做不出来" → 代码在客户仓库 + 里程碑付款 + 每周演示
  - "AI 不可信" → 屏幕共享真实工具链演示（Claude Code 实操 5 分钟）

## Day 3 — 签约

- 电子签 + 30% 定金 → 建项目频道 + 客户 Git 仓库 + 欢迎邮件
- 当天发出 kickoff 时间邀约（趁热）

## 红线

- 任何线索 >24h 无响应 = 事故，仪表盘黄色计数必须当日清零
- 不在邮件里砍价；价格变动必须伴随范围变动
- Sample 案例就说是 sample（页面已有水印），不冒充真实客户
