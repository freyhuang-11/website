## 7. 对外口径

### 必须这样说

| 场景 | 说法 |
|---|---|
| 一句话定位 | 给小生意自己用的 AI 营销视频和海报工具 |
| 卖点 | 写几句话说清卖什么（或传一张产品照片），就出 15 秒营销视频或海报；不用拍、不用剪、不用自己出镜 |
| 产品核心 | 店老板不用动脑：选个行业、选个类型、写几句话，其余都有默认设置 |
| 谁来做 | 客户自己在网站上做：「注册就送 100 积分，你自己在网站上做」 |
| 主推痛点 | 生意好的店都靠多发视频来客人；自己不会做，请人拍又太贵 → 在网站上打一句话就有 |
| 4 个模块名 | 视频制作 / 海报制作 / 长视频制作 / 爆款复刻；Make a Video / Make a Poster / Long Video / Copy a Hit Video |
| 语言 | 全语言通用 |
| 价格 | 见第 6 节公开写法 |
| 结尾 | Try it free at thinknova.top |

### 禁止说

- 「第一条免费」「we make it for you」这类像代做的话；PPT 不提代做服务。
- 英文避免 hire / job / apply / earn / work / join / creator（东南亚用户会误会成招聘）。
- 具体几分钟出片；效果承诺和效果数字（涨粉、带客、营业额、播放量、保证爆）。
- 客户数量、用户数和任何经营数字；编案例、编客户经历。
- 绝对化用语：最、第一、唯一、100%、保证；假倒计时、假限量、假涨价。
- 积分有效期（包括「不过期」）、作品保存天数。
- 「智能体」这个叫法（统一用 4 个模块名）。
- 把学校或机构写成为我们背书、写成正式合作伙伴。
- 画面里出现 AI 生成的真人时，标「AI 示例 · 非真实客户」。
