## 7. 对外口径（老板定）

### 必须这样说

| 场景 | 说法 |
|---|---|
| 一句话定位 | 给小生意自己用的 AI 营销视频和海报工具 |
| 卖点 | 写几句话说清卖什么（或传一张产品照片），就出 15 秒营销视频或海报；不用拍、不用剪、不用自己出镜 |
| 产品核心 | 店老板不用动脑：选个行业、选个类型、写几句话，其余都有默认设置 |
| 谁来做 | 说清是**客户自己在网站上做**：「注册就送 100 积分，你自己在网站上做」 |
| 主推痛点 | 生意好的店都是靠多发视频来客人的；自己不会做，请人拍又太贵（英文写 a videographer costs too much）→ 在网站上打一句话就有 |
| 画面能力 | 想要什么样的视频都可以换，区别只在语言 |
| 4 个功能名 | 视频制作 / 海报制作 / 长视频制作 / 爆款复刻（中文）；Make a Video / Make a Poster / Long Video / Copy a Hit Video（英文） |
| 价格 | 见第 6 节「公开写法」 |
| 急迫感 | 只用真实理由：11.11、12.12、圣诞、年底旺季 |
| 语言风格 | 短句、日常词、一条只讲一件事、不能有两种读法 |
| 结尾 | 英文 Try it free at thinknova.top |
| 能说的真话 | 我们自己账号的内容也是用它做的 |

### 禁止说

- ⛔「第一条免费」「we make it for you」「ThinkNova makes the video for you」这类像代做的话。
- ⛔ 英文：hire / hiring / job / apply / earn / work / join / creator，以及「免费试做一条给你看」这类词（东南亚用户会误会成招聘或代做）。
- ⛔ 有字幕功能（15 秒视频没有字幕，只有长视频有）；⛔ 多语言配音（长视频只有中文音色）。
- ⛔ 具体几分钟出片。
- ⛔ 效果承诺和效果数字：涨粉、带客、营业额、播放量、「保证爆」「提升销量 X%」。
- ⛔ 客户数量、用户数和任何经营数字。
- ⛔ 编案例、编客户经历。
- ⛔ 绝对化用语：最、第一、唯一、100%、保证。
- ⛔ 假倒计时、假限量、假涨价。
- ⛔ 积分有效期（包括「不过期」）、作品保存天数。
- ⛔「智能体」这个叫法（统一用上面 4 个功能名）。
- ⛔ 学校或机构为我们背书。
- ⛔ 「对手天天在发视频」「客人刷到的都是别家」。
- ⛔ 海报「用你自己的照片做底图」（海报线不支持上传照片）。
- 画面里出现 AI 生成的真人时，标「AI 示例 · 非真实客户」。
